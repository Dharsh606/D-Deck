Privacy Policy

Effective Date: October 2026 • Document Version: 1.0.0

1. Principle of Complete Local Privacy

D-Deck is engineered on a zero telemetry, local first architecture. We believe that your schedule, daily routines, habits, and tasks belong entirely to you. D-Deck does not track, collect, upload, or sell your personal data. There are no user accounts, no cloud databases, and no remote servers connected to the software.

2. Local Storage and File Location

All information created in D-Deck, including task titles, tags, routine definitions, completion states, settings, and velocity metrics, is stored exclusively on your local hard drive.

Windows Directory: %APPDATA%\d-deck\d-deck-data.json

This file never leaves your machine unless you manually export or move it.

3. Zero Network Tracking and Telemetry

The desktop application operates completely offline. Specifically:

  • No analytics SDKs or tracking pixels are included in the source code.
  • No crash reports or diagnostic telemetry are transmitted across the internet.
  • No outbound network calls are made during task creation, sprint timing, or reminder alerts.
  • Audio chime notifications and desktop reminders are processed 100% locally through native browser and operating system APIs.

4. User Rights and Data Control

Because your data is stored in standard JSON format in your user directory, you retain unconditional control:

  • Export: You can export a full JSON backup of your records at any time directly through the Command Deck settings.
  • Portability: You can transfer your data file to any other computer running D-Deck.
  • Deletion: Uninstalling the application or deleting the data file permanently wipes your data from the system with no remote backups remaining.

5. Third-Party Code and Dependencies

D-Deck is open-source software built using React, Electron, and standard web technologies under the MIT License. All dependencies are open for public audit on our GitHub repository.
