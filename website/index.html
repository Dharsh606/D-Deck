Open-Source Desktop HUD Widget & Personal Command Center

Your agenda on your desktop.
Translucent glass, zero friction, 100% offline.

D-Deck is a compact, floating Windows HUD widget and command deck crafted for developers, gamers, and focused multitaskers. Completely free of preloaded clutter, with custom manual tags, Focus Flow sprint timers, and continuous precision reminders.

Download for Windows (.exe) Source Code (GitHub)
HUD

50% Smaller Floating HUD

Streamlined translucent frosted glass widget that stays discreetly on top. Toggle instantly anywhere on Windows with global stealth hotkey Ctrl+Shift+D.

1m

Continuous Precision Reminders

Alerts 1 minute before task time, at the scheduled minute, and repeats every minute until completed. Accompanied by custom audio notification chime.

25m

Focus Flow HUD Sprint Timer

1-click countdown sprint timer embedded in the widget titlebar (15m, 25m, 45m, 60m). Soft glowing feedback with audio completion chime.

24h

Daily Habit Auto-Reset

Toggle everyday routine tasks (workout, gaming, coding review). At midnight, completed routines automatically reset to unchecked for the new day.

TAG

Custom Manual Tags

No hardcoded categories or dummy presets. Tag tasks freely (e.g. Gaming, Coding, Project, Workout) and filter backlogs dynamically.

100%

Offline Velocity & Consistency

Built-in streak counter measuring active days and 7-day velocity. Zero telemetry, zero cloud trackers, saved strictly on your local PC in %APPDATA%.

Technical Architecture & Standards

✓ Windows auto-start on desktop login
