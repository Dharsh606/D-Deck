D-Deck is a compact, floating Windows widget and command deck crafted for developers, gamers, and focused creators. Segregate your coding sprints, project backlogs, gaming sessions, and daily routines with 3-stage precision reminders.

Download for Windows (.exe) Source Code (GitHub)
HUD

Ultra-Compact Widget

Floats quietly in any screen corner with persistent desktop coordinates. Add tasks in two clicks without interrupting what you're doing.

3x

3-Stage Smart Reminders

Monitors task times at 5 minutes before, at the exact time, and 5 minutes after if still pending. Automatically stops when marked complete.

100%

Local-First Privacy

Zero cloud databases, zero telemetry, zero monthly subscriptions. Your entire backlog is saved in your local Windows AppData directory as JSON.
