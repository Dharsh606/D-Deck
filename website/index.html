CORE ARCHITECTURE

Built for pure focus, zero distractions

Engineered specifically for users who need task management without third-party cloud servers or window clutter.

HUD

Stealth Desktop HUD

Zero Taskbar Clutter • Ctrl + Shift + D

Floats cleanly on your desktop canvas without polluting the Windows taskbar or Alt+Tab switcher. Press the stealth hotkey anywhere in Windows to toggle the widget to the foreground or hide it instantly.

✓ Windows 11 Acrylic Glass • ✓ System Tray Minimize
TIMER

Focus Flow Sprints

One-click sprint timer directly in the titlebar (15m, 25m, 45m, 60m). Plays a gentle chime notification when your sprint completes.

Header embedded countdown
AUTO

Daily Routine Auto-Reset

Mark recurring tasks as a Daily Routine. Check them off during the day. At midnight, completed routines automatically reset to unchecked for the next morning.

Zero manual re-typing
ALERTS

Continuous Reminders

Alerts you 1 minute before task time, on exact time, and every minute thereafter until marked complete or snoozed.

Precision audio chime
LOCAL

100% Offline and Private

No cloud accounts, no subscriptions, and zero tracking. All tasks and metrics are stored in a single JSON file in %APPDATA%/d-deck.

Complete data ownership
