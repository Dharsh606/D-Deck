Open-source desktop widget for Windows

A desktop to-do widget with separate lists and water tracking.

D-Deck stays on your Windows desktop as a draggable widget. Add tasks in two clicks, track your daily 3.5L water target, and keep coding, gaming, projects, and movies in distinct lists.

Download for Windows (.exe) Source Code (GitHub)

Desktop Widget

Stays on your desktop or floats above windows. Click the plus button to quickly add a task without opening heavy applications.

Categorized Lists

Pre-built spaces for Coding, Projects, Gaming backlog, Movie watchlist, Daily errands, and Fitness.

Local Storage

100% offline. Stored in your local AppData directory as JSON. Zero cloud databases, accounts, or telemetry.

Technical Details

✓ Auto-start with Windows on login
✓ Native Windows toast notifications
✓ 3.5L daily water goal with quick logging
✓ Single JSON file backup & export
✓ Minimal CPU and RAM usage
✓ Dual widget and full-view modes
